# AI Agent 大量表格查询结果的交付思路

## 临时想法

当查询接口返回大量表格数据时，后端将完整结果生成并保存为 Excel 文件，只向模型提供部分数据（例如字段说明、样例数据和必要的统计信息），同时要求模型把完整文件交付给用户。

前端可以嵌入 Excel 预览，方便用户直接查看、筛选和核对完整数据。模型不再用 Markdown 表格转述全部结果，而只负责提炼重点、解释异常并给出总结，从而降低数据在转述过程中出现遗漏或错误的风险。

## 核心分工

- Excel 文件：承载完整、可核对的查询结果，作为数据交付物。
- 模型上下文：只接收完成分析所需的部分数据和元信息。
- 模型回复：提供重点提要、解释和总结，并附上文件。
- 前端：内嵌预览 Excel，同时保留下载入口。

## 待确认

- 模型需要看到哪些样例、统计信息或字段元数据，才能可靠总结完整数据。
- Excel 是查询结果的权威快照，还是仅作为一次性导出文件。
- 如何处理数据量过大、敏感字段、权限控制和文件过期。
- 前端嵌入式预览需要支持哪些能力，例如分页、筛选、排序和搜索。
